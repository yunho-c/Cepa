Candidate baseline: 61ba647 plus the request-lifecycle working-tree change

Invariant under test
- estimate and directory-search tokens are allocated while replacing the active
  backend request under the same lock
- a concurrent newer request cancels every earlier owner, and an earlier finish
  cannot clear the latest request
- compression plan ID, generation, prepared plan, and cancellation token are
  one atomic lifecycle
- plan completion can install only the current still-preparing generation
- current preparation failure cancels and invalidates that generation, while a
  stale failure cannot clear a newer preparation or stored plan

  cancellation token was set and the stored plan returned token 16 exactly
- a stale plan failure preserved the current stored plan and token
