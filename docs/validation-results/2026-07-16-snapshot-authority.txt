Invariant under test
- a new scan invalidates and detaches the completed snapshot before cancelling
  search, estimate, and dormant-plan state
- Home detaches the completed snapshot before the same auxiliary sweep
- search, estimate, and plan preparation install their request owner, then
  require both the scan ID and exact retained snapshot identity to remain current
  before dispatching blocking work

  to start after the sweep rejects itself instead of retaining stale authority
- production search and estimate code cannot call an unscoped start entry point
