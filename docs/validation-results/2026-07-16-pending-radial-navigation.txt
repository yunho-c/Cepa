Reproduction before the fix
- At 620x480 dark, mock=stale-actions held chart-origin directory navigation
  for 1.2 seconds.
- During that request, the explorer reported aria-busy=true and the list had
  pointer-events:none, but the radial group exposed no busy state, its focused
  segment had no aria-disabled state, and the chart stayed at full opacity.
- The chart handlers still accepted pointer previews and roving keys. A file
  activation rejected by inspectEntry could first overwrite the inspector's
  return target.

Deterministic browser validation after the fix
- Focused the Library segment, dispatched Enter, awaited the Svelte update, and
  dispatched End before the delayed request settled.
- The Library segment retained focus, exposed aria-disabled=true without a
  native disabled attribute, and the radial group exposed aria-busy=true.
- End did not move the roving focus, and the viewport had no horizontal
  overflow at 620x480.
- The pending chart style uses the same 0.45 opacity as the busy list and a wait
  cursor without removing pointer or keyboard focus ownership.
