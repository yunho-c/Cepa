Reproduction before the fix

- Dispatched the shared Alt+Left desktop command while the focused Search
  control remained mounted.
- Navigation set native disabled on Search; activeElement became BODY. The Up
  control already exposed aria-disabled=true but did not own focus.
- An active search input would likewise be removed before navigation settled.

- Repeated Alt+Left from focused Search with the 1.2-second delayed request.
- The visible Up control received focus synchronously, exposed
  aria-disabled=true without a native disabled attribute, kept BODY unfocused,
  and produced no horizontal overflow.
- After navigation settled, the root storage-map heading received focus.
